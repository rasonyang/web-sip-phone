Account

Domain is the hostname only — no sip:, scheme, port, or path. To reach the server on a different scheme, port, or path, use Server URL below.

Optional, advanced. Leave it empty to use wss://<domain>/. Set it to reach the server on a non-standard port or path, for example wss://voice.example.com:7443/ or ws://192.168.1.10:5066/. Warning: ws:// is unencrypted — SIP signaling and your credentials travel in the clear, and anyone on the network path can replace the DTLS fingerprint in the SDP and listen to your call audio. Use it only on a network you trust.

Saving does not connect. Web SIP Phone registers automatically when an Allow Site page is open.

Allow Sites

Exact hostname match: no wildcards, no scheme, port, or path in the box, and subdomains are not included automatically. Ports never take part in matching, so one entry covers every port on that host (crm.example.com matches https://crm.example.com:8443/tickets). HTTPS only, except private-network addresses — localhost and any .localhost name, 127.x, 10.x, 172.16.x–172.31.x, 192.168.x — which are also allowed over HTTP.

    TURN

    Default STUN: stun:stun.l.google.com:19302. Configure TURN only if calls fail to carry audio. Changes affect subsequent calls only.
