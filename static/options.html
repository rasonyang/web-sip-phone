Configure a SIP account manually

Saving does not connect. Web SIP Phone registers automatically when an Allow Site page is open.

Allow Sites

Enter the exact hostname of an HTTPS site.
One entry covers every port and path on that host; subdomains must be added separately.

Private-network hosts (localhost, 127.x, 10.x, 172.16–31.x, 192.168.x) are also accepted over HTTP.
